## 2. GLOBAL BENCHMARK CASE STUDIES & OPEN-SOURCE PRECEDENTS

SAKU's architecture synthesizes best practices from 4 world-class open-source finance engines:

### 2.1 Preseden 1: Firefly III (`firefly-iii/firefly-iii` — 24k+ Stars)
* **Domain Focus**: Double-Entry Personal Ledger & Rule Engine.
* **Key Architecture Taken for SAKU**:
  - Transaction journals must strictly balance across Debit and Credit legs.
  - Automated rule matcher engine (`IF description CONTAINS 'QRIS' THEN category = 'Food'`).

### 2.2 Preseden 2: Ghostfolio (`ghostfolio/ghostfolio` — NestJS + Prisma)
* **Domain Focus**: Multi-Asset Portfolio & Net Worth Intelligence.
* **Key Architecture Taken for SAKU**:
  - NestJS + PostgreSQL + Prisma stack architecture.
  - Return on Average Investment (ROAI) and diversification risk metrics.

### 2.3 Preseden 3: Maybe Finance (`maybe-finance/maybe` — Modern Wealth OS)
* **Domain Focus**: Institutional-grade Net Worth UI & Real-Time Aggregation.
* **Key Architecture Taken for SAKU**:
  - High-density dark mode financial UI layout.
  - Real-time time-series Net Worth evolution charts.

### 2.4 Preseden 4: TradeZella & Myfxbook (Active Trading Performance Engine)
* **Domain Focus**: MetaTrader Quantitative Performance Analytics.
* **Key Architecture Taken for SAKU**:
  - MQL5 Expert Advisor read-only state export.
  - Expectancy, Profit Factor, Win Rate %, Drawdown, and MAE/MFE scatter analysis.
