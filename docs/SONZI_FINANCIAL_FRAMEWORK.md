# 🛡️ SONZI FINANCIAL MANAGEMENT FRAMEWORK IN SAKU
## DEFAULT ENGINE, RISK PROFILES, & ONBOARDING PRESETS

---

### EXECUTIVE OVERVIEW

The **SONZI Financial Framework** serves as **SAKU's Standard Built-in Default Engine**. It provides users with an intelligent, out-of-the-box financial roadmap without requiring manual setup from scratch.

However, recognizing that every individual possesses a unique risk tolerance and life stage, SAKU allows users to seamlessly switch or fine-tune their framework preset based on their **Risk Profile**.

## 2. PROVIDER-AGNOSTIC ROLE ARCHITECTURE

While SONZI provides the default allocation logic, users map their own real-world bank accounts, e-wallets, or brokers to SAKU's functional roles:

* **`INCOME_HUB`**: Primary Bank Account (BNI, BCA, Mandiri, BRI, DBS, etc.)
* **`ALLOCATION_HUB`**: Pocket Digital Bank (Bank Jago, Blu, SeaBank, Dana, etc.)
* **`SECURITIES_DESTINATION`**: Stock & Mutual Fund Broker (Ajaib, Stockbit, Bibit, Bareksa)
* **`CRYPTO_DESTINATION`**: Crypto Exchange (Pluang, Indodax, Tokocrypto, Bybit)
* **`TRADING_DESTINATION`**: MT4/MT5 Trading Account (HFM, Exness, XM, etc.)

## 3. ONBOARDING WORKFLOW INTEGRATION

```
[USER ONBOARDING] ──► [DEFAULT: SONZI ENGINE SELECTED] ──► [OPTION TO SELECT RISK PROFILE] ──► [MAP ACCOUNTS]
```

1. **New User Registration**: SAKU automatically activates the **SONZI Standard Default Engine**.
2. **Profile Questionnaire / Selector**: User can keep the SONZI default, choose a Conservative/Moderate/Aggressive preset, or customize percentage sliders.
3. **Account Mapping**: User links or creates their real-world bank, e-wallet, and broker accounts to the corresponding SONZI roles.
